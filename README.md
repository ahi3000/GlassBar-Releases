# GlassBar – Downloads

Fertige Versionen von **GlassBar**, einem schwebenden Glas-Dock als Ersatz für die Windows-Taskleiste.
Der Quellcode ist privat; hier liegen nur die Releases.

## Installieren

1. Unter [Releases](../../releases/latest) die Zip für deinen PC laden: `win-x64` (normale PCs) oder `win-arm64`.
2. Entpacken, z. B. nach `%LocalAppData%\Programs\GlassBar`.
3. `GlassBar.exe` starten. Admin-Rechte sind nicht nötig.

Voraussetzung: [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64 bzw. Arm64).

## Updates

Einstellungen → System → „Updates aus dem Internet“ einschalten. GlassBar prüft dann diese Seite – ohne GitHub-Konto –
und installiert neue Versionen per Klick.

Die Windows-Taskleiste kommt jederzeit zurück: Startmenü → „GlassBar – Taskleiste wiederherstellen“.
